# Multi-Agent-Financial-Intelligence-System
A multi-agent AI system that autonomously fetches financial data, analyzes transactions, and generates structured, actionable reports through coordinated agent workflows.



## 🚀 How to Run  

Follow these steps to set up and run the project locally:

---

### 1️. Clone the Repository  

```bash
# Clone this repository
git clone https://github.com/shreejoysarkar/Multi-Agent-Financial-Intelligence-System.git

```

### 2. Create a uv enrionment after opening the repository
```bash
## initializing uv 
## (paste these command in the cmd)

uv init 

uv venv fingent --python 3.13

#### Activating the env

fingent\Scripts\activate
```

### 3. Installing requirements

```bash
uv pip install -r requirements.txt
```
